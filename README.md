# Park Atlas Open Data

Cleaned, joined datasets covering the U.S. National Park System's 474 units,
extracted from official federal sources and refreshed on theparkatlas.com nightly.
This repository snapshot: data retrieved August 29, 2026.

| File | Contents |
|---|---|
| `parks.csv` | Master table: all 474 units with type, state, 2025 visitation, Dark Sky certification, reservation requirement, bird species count |
| `entrance_fees.csv` | Every published entrance fee and park pass |
| `campgrounds.csv` | Park Service campgrounds with size, reservability, amenities |
| `wildlife_checklist_counts.csv` | Official NPSpecies bird/mammal counts per park |

**Sources:** National Park Service API, NPS visitation statistics (IRMA), NPSpecies,
Recreation.gov RIDB, DarkSky International certifications. Public-domain federal
data; this compilation is provided as-is under CC0. Attribution appreciated:
[The Park Atlas](https://theparkatlas.com).

Live, browsable versions of all of this: https://theparkatlas.com
